# Machine Learning Projects

A collection of Jupyter notebooks exploring practical data analysis and introductory machine learning workflows with public datasets.

## Topics covered

- Data cleaning and exploratory analysis
- Regression using an e-commerce dataset
- Logistic regression using the Titanic dataset
- Notebook projects with weather, cars, and online course datasets

## Repository contents

The notebooks contain the analysis and model workflows. CSV files are included alongside selected projects as their datasets.

## Getting started

Open a notebook in GitHub to preview it, or run it locally with Jupyter Notebook or JupyterLab. Install the Python libraries imported in the notebook before running its cells.

## Notes

This repository collects learning projects. Review each notebook for its data preparation steps, assumptions, and results.
